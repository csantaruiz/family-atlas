# Santa Ruiz Family Atlas

## Design Principles

Mission: Transform genealogy into an immersive historical documentary.

Core principles:
1. Story before information.
2. Progressive revelation.
3. AI adds meaning.
4. Every screen has a wow moment.
5. Geography serves story.
6. Premium restraint.
7. Cinematic motion.
8. Visual hierarchy.
9. Generic architecture.
10. Build horizontally.
11. Minimize regressions.
